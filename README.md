# 招标公告自动化采集系统

## 项目简介

这是一个专门用于自动采集和管理招标公告的系统，主要针对杭州市临安区公共资源交易网的招标信息。系统支持多种公告类型的采集、关键词过滤、自动分页、详情页抓取以及数据存储等功能。

## 核心功能

- 🤖 **自动采集** - 支持自动分页采集多种类型的招标公告
- 🔍 **关键词过滤** - 可根据关键词筛选相关项目
- 📊 **详情页抓取** - 自动抓取项目编号、总投资额、竞包截止时间等详细信息
- 💾 **数据库存储** - 将采集的数据存储到MySQL数据库
- 📋 **完整日志** - 详细的操作日志记录
- 🖥️ **多端支持** - 提供命令行和Web界面两种使用方式
- 📱 **数据导出** - 支持JSON格式数据导出

## 技术栈

- **开发语言**: PHP 7.4+
- **HTTP客户端**: Guzzle 7.0+
- **HTML解析**: DOMDocument + DOMXPath
- **数据库**: MySQL 5.7+
- **依赖管理**: Composer

## 安装说明

### 1. 环境要求

- PHP 7.4 或更高版本
- MySQL 5.7 或更高版本
- Composer

### 2. 安装步骤

1. **克隆项目**
   ```bash
   git clone https://github.com/ma992211320/Announcement-Collection.git
   cd Announcement-Collection
   ```

2. **安装依赖**
   ```bash
   composer install
   ```

3. **配置数据库**
   - 修改 `config.php` 文件中的数据库配置
   - 创建数据库（如果不存在）

4. **初始化数据库**
   ```bash
   php init_db.php
   ```

5. **启动服务**
   - Web界面：通过浏览器访问 `index.php`
   - 命令行：使用 `php cli.php` 命令

## 使用方法

### 命令行使用

```bash
# 采集所有招标公告
php cli.php --type="招标公告"

# 采集变更公告并按关键词过滤
php cli.php --type="变更公告" --keyword="工程"

# 导出为JSON格式
php cli.php --type="中标公告" --export=json
```

### Web界面使用

1. 打开 `index.php` 在浏览器中
2. 选择公告类型
3. 输入关键词（可选）
4. 点击「开始采集」按钮
5. 查看采集结果和日志

## 配置说明

主要配置项位于 `config.php` 文件中：

- **数据库配置**：数据库连接信息
- **爬虫配置**：基础URL、User-Agent、超时设置等
- **公告类型配置**：支持的公告类型及其编码
- **日志配置**：日志文件路径

## 注意事项

1. **频率限制**：系统内置了2秒的请求间隔，避免对目标网站造成过大压力
2. **错误处理**：即使数据库连接失败，爬虫仍会继续执行并采集数据
3. **数据去重**：系统会自动检查重复公告，避免重复存储
4. **日志记录**：所有操作都会记录到 `crawler.log` 文件中
